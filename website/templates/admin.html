Coder — model ladder

The coder's model ladder. First Attempt runs first; on repeated failure the diagnose-first check decides whether to climb to the next model (spec/env defects route away instead — a stronger model won't fix those). Each tier picks a backend · model · #attempts. Ollama tiers — including MiniMax / GLM served through Ollama — are free; claude-api / openai tiers are paid and bounded by the daily USD cap below. Leave a tier's Model blank to omit it. Empty ladder ⇒ the coder runs your Ollama coder model (Ollama tab) as a single tier. Exhausting the last tier → the feature is Blocked for triage. API keys: Anthropic / OpenAI tabs.
